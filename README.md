# RKVeda Website

Responsive React + Vite corporate/umbrella-brand website for RKVeda.

- Base: Vrindavan, Mathura, Uttar Pradesh, India

## Important location wording
RKVeda is presented as **based in Vrindavan, Mathura** and **serving digitally across India**. This does not claim a public walk-in office or Google Business Profile physical storefront.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
The generated `dist/` folder can be deployed to any static hosting provider. For Hostinger Node.js/Vite deployment, use the normal build command and serve the `dist` output according to your hosting setup.

## Email note
The supplied string `info.rkveda.in` is a domain, not a complete email address, so this build uses the conventional address `info@rkveda.in`. Change `EMAIL` in `src/main.jsx` if you have a different mailbox.
